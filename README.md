## About this repository

Source code for [ken-automate.onrender.com](https://ken-automate.onrender.com/), built with React, TanStack Router, Tailwind CSS and Vite, and edited with [Lovable](https://lovable.dev). Pushing to `main` deploys the site on Render and syncs to Lovable.

```sh
npm install
npm run dev     # local preview at http://localhost:8080
npm run build   # production build, including the pre-rendered homepage for crawlers
```
